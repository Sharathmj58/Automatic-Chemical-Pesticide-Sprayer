## Automatic Chemical Pesticide Sprayer

This project automates pesticide spraying in agriculture using an ESP32 microcontroller, DC pump, solenoid valves, and sensors.

### Main Objectives
- Reduce manual labor and save time.
- Ensure efficient pesticide spraying.
- Minimize unnecessary chemical usage.
- Improve farming efficiency through automation.

**Technologies Used:** ESP32, Raspberry Pi, Sensors, DC Pump, Solenoid Valves.
